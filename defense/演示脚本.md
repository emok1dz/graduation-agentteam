# 现场演示脚本（5 分钟）

> 演示主线：**管理员看全局 → 教师看题库/试卷/监控 → 学生作答并交卷 → 教师批改与统计 → 学生看结果**。
> 账号、种子数据以 `backend/README.md §3` 为准。备用截图均在 `docs/screenshots/`。

## 一、演示前准备（答辩前 10 分钟完成，不计入 5 分钟）

```bash
cd backend
rm -f data/db.json      # 可选：清空旧数据，下次启动自动写入种子数据
npm start               # 等价于 node server.mjs，零依赖，无需 npm install
# 浏览器打开 http://localhost:3000
```

- 环境：Node.js ≥ 18（测试环境为 v22），Chrome / Edge 最新版。
- 种子数据（首次启动自动写入）：班级“计科2101”；teacher1 的 3 个标签、10 道示例题（单选 3、多选 2、判断 2、填空 2、简答 1）；示例试卷“数据结构与网络基础 · 示例试卷”（10 题，总分 100）；**进行中**的考试“期中测验（示例 · 进行中）”（开始于启动前 10 分钟，持续 30 天，时长 90 分钟，及格线 60）。
- 种子账号：

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| `admin` | `admin123` | 管理员 |
| `teacher1` | `teacher123` | 教师（王老师） |
| `student1` | `student123` | 学生（张三，计科2101） |
| `student2` | `student123` | 学生（李四，计科2101，备用） |

- 建议开两个浏览器窗口：普通窗口登录教师、无痕窗口登录学生（令牌存于 localStorage，同一窗口只能一个账号）。
- 提前把 `docs/screenshots/` 文件夹在文件管理器中打开，作为备用；`defense/答辩PPT.html` 放在另一标签页。
- 浏览器缩放 110%~125%，保证后排可见。

## 二、时间轴

| 时间 | 窗口 / 操作 | 讲解词（参考） |
| --- | --- | --- |
| 0:00–0:20 | 终端展示 `npm start` 已启动；浏览器打开 `http://localhost:3000`，停在登录页 | “系统后端只用 Node.js 内置模块，零第三方依赖，一条命令就能启动，前端页面由同一个端口提供。” |
| 0:20–0:50 | 登录 `admin / admin123` → 管理员概览 → 点“用户管理” | “管理员负责用户和班级。这里能看到系统概览，用户可按角色筛选、禁用、重置密码；密码在库里只存 scrypt 哈希和盐。” |
| 0:50–1:30 | 退出，登录 `teacher1 / teacher123` → 题库管理（教师首页）→ 点“新增题目”，切换题型展示五种题型表单（不保存）→ “试卷管理”打开示例试卷预览 | “教师首页是题库，支持五种题型、难度和知识点标签。组卷支持手动选题和按规则随机抽题，这份示例试卷 10 道题、总分 100。” |
| 1:30–1:45 | “考试管理” → 示例考试 → “监控” | “这场考试正在进行，监控页每 15 秒自动刷新，可以看到每个学生的作答状态。” |
| 1:45–2:00 | 切到无痕窗口，登录 `student1 / student123` → 我的考试 | “学生登录后只能看到本班的考试。” |
| 2:00–2:15 | 点考试 → 考试须知 → 勾选同意 → 开始作答 | “开始时间、截止时间都以服务器时间为准，改本机时钟不能延长作答。” |
| 2:15–3:00 | 作答：第 1 题选 B（显示“已保存”）；多选第 4 题选 A、B、D；填空第 8 题输入 `80`；简答题输入几句话（等 2 秒出现“已保存”）；按 F5 刷新页面 | “选择题点选即保存，文本题 2 秒防抖保存。现在刷新页面——答案都恢复了，倒计时也没有重置。断网时会提示并把答案暂存本地，恢复后自动重试。” |
| 3:00–3:15 | 点“交卷” → 确认框显示未答题数 → 确认 → “已交卷，等待成绩发布” | “交卷有二次确认。后端交卷是幂等的，测试中 10 个并发交卷请求只有 1 个成功。客观题此时已自动判分。” |
| 3:15–4:10 | 切回教师窗口 → 考试“批改” → 打开 student1 答卷 → 简答题给分并写评语 → 保存；点“发布成绩” | “客观题系统自动判分，多选题必须完全正确才得分；简答题由老师人工给分。注意发布成绩时系统提示‘考试尚未结束，结束后才能发布成绩’——这是业务规则：防止考试过程中泄露答案和分数。” |
| 4:10–4:45 | 点“成绩统计” | “统计页给出应考/实考人数、平均分、及格率、分数段分布和每题正确率，柱状图是原生 SVG 画的。成绩单支持导出 CSV。” |
| 4:45–5:00 | 切回学生窗口 → “我的成绩” | “成绩未发布前，学生端接口返回的分数为空，前端也就看不到分数。演示到此结束，谢谢。” |

> 若时间富余（或老师追问发布后效果）：可展示截图 `flow-teacher-monitor.png`（发布被拒提示）与学生成绩详情的 E2E 结论（测试报告 E2E-06：总分 10、及格、显示评语与参考答案）。
> 若想现场演示完整“发布成绩 → 学生查看”，需在答辩前以 teacher1 新建一场短时考试（开始=当前+2 分钟、窗口 5 分钟、时长 3 分钟、班级 计科2101），让 student2 作答后等待考试结束再发布；该流程有等待时间，**不建议放在 5 分钟主线内**。

## 三、演示失败时的备用方案

| 故障 | 处理 | 备用截图（`docs/screenshots/`） |
| --- | --- | --- |
| 端口 3000 被占用 | `PORT=3001 npm start`，访问 http://localhost:3001 | — |
| 启动报 db.json 解析失败（数据文件损坏时系统拒绝启动以保护数据） | `rm -f data/db.json` 后重启，自动重建种子数据 | — |
| Node 版本过低 / 电脑无法运行 | 直接切换到截图讲解，按下表顺序 | 见下 |
| 账号被锁定（5 次错误锁 10 分钟） | 换用 `student2` / 重启服务前删 `data/db.json` | — |
| 学生已交过卷无法再作答（每人每场只能作答一次） | 改用 `student2 / student123` 演示作答 | — |
